# 文档状态：从文本内容到可探索的文档空间

**Q：** 什么叫文档状态?

## 要点

- 文档状态不是单纯的文本内容，而是文档在系统中的结构、位置、关系和证据路径。
- 以合同分析为例，系统应知道：这段文字来自哪份合同、属于哪个章节、附件里有没有相关表格、补充协议有没有改过这条、结论能否回到原文复核。
- 文档状态可表示为：Document -> Section -> Chunk -> Asset -> Metadata -> Source Path -> Graph Link -> Retrieval Trace。
- Agent拿到的不是孤立纸条，而是可以继续探索的文档空间。
